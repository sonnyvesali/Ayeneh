# Ayeneh ellipse mirror — monochrome vector study

Import `01-silver-rim.svg`, `02-mirror-face.svg`, and `03-reflected-light.svg` into Icon Composer in that stacking order. They share a 1024 × 1024 transparent canvas. The rim is an outlined filled ring with a dark outer edge and a light inner edge; the face and reflected-light band use restrained grayscale gradients. The face fits inside the rim. All artwork is editable vector geometry, with no raster textures, handle, crest, or app-icon background.

`ayeneh-mirror.svg` combines the three layers for standalone use. `preview-light.svg` and `preview-dark.svg` are context checks only; their backgrounds are not part of the mirror exported to Icon Composer. Tune the native material and choose the app-icon background in Icon Composer.
